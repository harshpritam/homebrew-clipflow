# homebrew-clipflow

Homebrew tap for [ClipFlow](https://github.com/harshpritam/ClipFlow) — a Windows-style clipboard manager for macOS.

## Install

```bash
brew tap harshpritam/clipflow
brew install --cask clipflow
```

## Uninstall

```bash
brew uninstall --cask clipflow
brew untap harshpritam/clipflow
```
